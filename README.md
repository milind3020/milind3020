* **Generative AI & LLMs:** Early Adopter of AWS GenAI standards. Experienced in fine-tuning LLMs (Mistral 7B, Llama 3) and building RAG pipelines that handle 500+ weekly queries with 80% faster lookup times.
* **Data Engineering:** Proven track record at Onit India, where I reduced monthly reporting cycles from 5 days to 3 using Spark SQL and scalable ETL pipelines.
* **Infrastructure:** Proficient in deploying Dockerized microservices and managing cloud infrastructure on AWS, Azure, and GCP.
